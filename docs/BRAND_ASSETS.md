# RITU brand assets

Updated October 5, 2026. The supplied `public/website_logo.jpg` and `public/icon_logo.jpg` supersede the earlier shared logo for the live website. Original JPEGs are preserved without edits.

| Placement                                  | Asset                                                             |
| ------------------------------------------ | ----------------------------------------------------------------- |
| Navigation logo                            | `public/website_logo.jpg`, imported by `src/components/shell.tsx` |
| Browser tabs, bookmarks, desktop shortcuts | `public/favicon.ico` (32px and 48px), `public/icons/ritu-48.png`  |
| Apple home-screen shortcuts                | `public/icons/ritu-180.png`                                       |
| Manifest shortcut icons                    | `public/icons/ritu-192.png`, `public/icons/ritu-512.png`          |
| Platforms that mask icons                  | `public/icons/ritu-maskable-512.png`                              |

All icons derive from `icon_logo.jpg`. Resizing preserves proportions and uses the supplied black background; the maskable version adds padding for the safe circle. The website logo uses a 2:1 display frame to hide only the large blank outer margins. Its full symbol and Bangla wordmark remain visible at tested desktop and phone widths.

Recreate the icons with `node scripts/generate-brand-icons.mjs` after replacing the source. The script uses Sharp installed with the current Next.js dependency tree. Icon metadata lives in `src/app/layout.tsx`; the automatically linked `/manifest.webmanifest` is generated by `src/app/manifest.ts`. The manifest identifies RITU, starts at `/`, and uses standalone display.

Reference: [Next.js icon metadata](https://nextjs.org/docs/app/api-reference/file-conventions/metadata/app-icons) and [MDN manifest icons](https://developer.mozilla.org/en-US/docs/Web/Progressive_web_apps/Manifest/Reference/icons).

Verification: Playwright checked 1440×1000, 390×844 and 320×800 farm pages in isolated contexts. The supplied website logo loaded; no horizontal overflow, framework error overlays or page errors occurred. Every linked favicon, Apple icon and manifest icon returned HTTP 200; PNG dimensions matched metadata, and the ICO contained both sizes. The home link returned to the farm route. Desktop and 320px screenshots and the 192px icon were visually inspected. Captures and the verification script remain under ignored `research/`.

These checks verify the assets and browser configuration. Physical-device installation and the OS shortcut appearance have not been tested. Previously created shortcuts may retain cached icons and need to be recreated. This change adds shortcut metadata, not offline caching.
