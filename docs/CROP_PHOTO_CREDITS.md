# Third-party crop photographs

Verified 25 October 2026. These are reference photographs, not NASA observations, inferred field conditions, or predicted growth. Only CC0/public-domain material was selected. Images are served locally without a stock-photo account or runtime image API. Rice seasons share one species reference. Mung beans are explicitly shown as harvested seeds.

The participant terms permit qualifying third-party materials and require licenses and citations: https://www.spaceappschallenge.org/legal/ . Wikimedia file rights were checked individually using the Commons imageinfo API and file pages; https://commons.wikimedia.org/wiki/Commons:Reusing_content_outside_Wikimedia .
